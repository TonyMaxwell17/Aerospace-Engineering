# UNNC Aerospace Engineering Toolkit & Code Repository

## About This Repository
This repository open-sources code, scripts, configuration files and learning resources for simulation and development software used during my BEng (Hons) Aerospace Engineering undergraduate studies at the University of Nottingham Ningbo China (UNNC).

Content covers course assignments, laboratory work, project practice and personal explorations, serving as a reference for aerospace engineering software workflows, reusable computation scripts and simulation automation solutions.

## About UNNC Aerospace Engineering Programme
Delivered by the Faculty of Science and Engineering, this programme follows the identical curriculum and quality standard as the University of Nottingham UK campus, and holds dual accreditation from the Royal Aeronautical Society (RAeS) and the Institution of Engineering and Technology (IET).

It offers 4+0 and 2+2 study pathways, with a curriculum spanning aerodynamics, aircraft structures, propulsion systems, flight dynamics & control, and aerospace design. The programme emphasises hands-on engineering practice and proficiency with industry-standard tools, supported by on-campus facilities including subsonic wind tunnels, flight simulators and additive manufacturing labs.

## Core Software & Tools Covered
### CAD & Mechanical Design
- **SolidWorks**: Primary 3D CAD tool for aerospace component modelling, assembly design, engineering drawing generation and basic FEA pre-processing, used across design modules and project-based coursework.

### Simulation & Analysis
- **ANSYS Fluent**: Core CFD tool for airfoil analysis, aerodynamic optimisation, heat transfer and propulsion system simulation, applied in aerodynamics modules and final-year research projects.
- **ANSYS Mechanical**: FEA platform for structural stress analysis, vibration simulation and aerospace structural dynamics validation.

### Programming & Numerical Computing
- **MATLAB / Simulink**: Core numerical environment taught from Year 1, widely used for mathematical computation, data visualisation, flight control system modelling and dynamic system simulation across dynamics, control and mathematics modules.
- **Python**: Applied to simulation result post-processing, data analysis and batch automation in coursework and projects, typically used via the Anaconda distribution available in university labs.
