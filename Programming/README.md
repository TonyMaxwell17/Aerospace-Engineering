# Programming

## Overview
This directory contains code scripts and reusable utilities developed throughout the Aerospace Engineering undergraduate programme at UNNC. It covers numerical computation, system modelling, data analysis and simulation post-processing, supporting coursework, laboratory work and project research.

All scripts are written for educational and reference purposes, aligned with the programme's mathematics, dynamics, control and engineering computing modules.

## Contents

### MATLAB / Simulink
The primary programming environment for engineering computation and dynamic system modelling across the curriculum.
- **Application scenarios**: flight dynamics solving, structural vibration analysis, control system design & simulation, numerical method implementation, mathematical coursework and data visualisation
- **Related modules**: AERO1005, AERO2003, AERO2004, AERO3009
- **Included assets**: executable scripts, Simulink model files, custom helper functions

### Python
Used for data processing, batch automation and post-processing of engineering simulation results.
- **Application scenarios**: CFD/FEA result post-processing, experimental data fitting & visualisation, batch parameter analysis, and automated workflow scripts
- **Common dependencies**: NumPy, SciPy, Matplotlib, Pandas
- **Typical use cases**: ANSYS Fluent batch data extraction, wind tunnel test data cleaning, and statistical analysis for project reports

## Usage Notes
- MATLAB scripts are tested on R2023b and above; compatibility with older versions may require minor adjustments.
- Python scripts are developed based on the Anaconda distribution (Python 3.10+); install required dependencies via `pip` or `conda` before running.
- File paths in scripts use relative paths by default; adjust working directory accordingly when running locally.
- All materials are for learning reference only. Please comply with UNNC academic integrity policies and complete assignments independently.
